# E-Grocery Market Web Project

**E-Grocery Market (HTML & CSS Project)**

---

## 2. Project Overview

This project is a simple **E-Grocery Market website layout** created using **HTML and CSS only**. The main aim of this project is to practice **CSS styling, layout techniques, and basic webpage structure**.

The webpage displays a grocery market interface with a header section and a product listing section. Each product is shown inside a card with an image, name, rating, price, and an add button.

This project does not use JavaScript and is completely static.

---

## 3. Objectives of the Project

* To understand basic HTML page structure
* To practice CSS styling and layout
* To use CSS Grid for product layout
* To design reusable product cards
* To improve frontend design skills

---

## 4. Technologies Used

* **HTML5** – for webpage structure
* **CSS3** – for styling and layout
* **Font Awesome CDN** – for icons (linked in project)

---

## 5. Project Structure

```
E-Grocery-Project/
│
├── index.html      (Main HTML file)
├── style.css       (CSS styling file)
└── images/
    └── e-grocery.avif
```

---

## 6. Description of Files

### index.html

* Contains the main structure of the webpage
* Includes header section with title, description, search bar, and image
* Contains product section with multiple product cards
* Uses semantic HTML elements like `header` and `section`

### style.css

* Used for styling the entire webpage
* Uses CSS reset with `*` selector
* Applies background colors and fonts
* Uses **CSS Grid** for product layout
* Adds hover effect on buttons

---

## 7. Page Sections Explained

### Header Section

* Displays the website title **E-Grocery Market**
* Contains a short tagline
* Includes a search input field
* Displays an image related to grocery shopping

### Products Section

* Displays products in grid format
* Each product card contains:

  * Product image
  * Product name
  * Star rating
  * Price
  * Add button

---

## 8. CSS Features Used

* CSS Grid (`grid-template-columns`)
* Flexbox in header section
* Border radius for cards and buttons
* Button hover effect
* Background colors and padding

---

## 9. How to Run the Project

1. Download or clone the project folder
2. Make sure `index.html` and `style.css` are in the same folder
3. Open `index.html` in any web browser
4. The E-Grocery Market webpage will be displayed

---

## 10. Limitations of the Project

* No JavaScript functionality
* Search bar is not functional
* Add button does not perform any action
* Product data is static

---

## 11. Future Improvements
